# Smart Parking System — Ақылды автотұрақ жүйесі

**Дипломдық жоба тақырыбы:** Ақылды автотұрақ жүйесін әзірлеу  
**Орындаған:** _Нусипахын Санжар_  
**Тобы:** _Иск 24-3a  _

## Жоба туралы

Smart Parking System — жүргізушілерге бос автотұрақ орындарын табуға, орын брондауға және кіру рұқсатын алуға мүмкіндік беретін ақпараттық жүйе. Жүйе автотұрақтағы орындар санын бақылайды, броньдарды тіркейді және шлагбаумға рұқсат командасын жібереді.

## Мақсаты

Автотұрақ орындарын тиімді пайдалану және жүргізушілердің бос орынды іздеу уақытын қысқарту.

## Пайдаланушылар

- Жүргізуші — орын іздеу, брондау және кіру рұқсатын алу.
- Әкімші — орындар мен броньдарды басқару.
- Автотұрақ операторы — құрылғылардың күйін бақылау.

## Талаптар

1. Жүргізуші жүйеге тіркеліп, авторизациядан өтеді.
2. Жүргізуші қолжетімді автотұрақ орындарын қарайды.
3. Жүргізуші бос орынды таңдап, брондау сұрауын жібереді.
4. Жүйе брондау алдында орынның бос екенін қайта тексереді.
5. Жүйе сәтті броньды деректер базасына сақтайды.
6. Жүйе жүргізушіге QR-код немесе кіру рұқсатын ұсынады.
7. Жүйе рұқсат расталғанда шлагбаумды ашу командасын жібереді.
8. Бос орын болмаса, жүйе пайдаланушыға хабарлама көрсетеді.
