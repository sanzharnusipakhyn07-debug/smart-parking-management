# Сценарий: Ақылды автотұраққа кіру

## Алғышарт
Жүргізуші жүйеге кірген, автотұрақ орындарының күйі жүйеде жаңартылған.

## Негізгі ағын
1. Жүргізуші қосымшаны ашады.
2. Жүргізуші бос орындарды сұрайды.
3. Қосымша Parking API-ға сұрау жібереді.
4. API деректер базасынан бос орындар тізімін алады.
5. Жүргізуші бос орынды таңдайды.
6. API орынның бос екенін қайта тексеріп, броньды сақтайды.
7. Жүйе жүргізушіге QR-код пен растау хабарламасын береді.
8. Жүргізуші кіру орнында QR-кодты көрсетеді, жүйе рұқсатты тексеріп, шлагбаумды ашады.

## Балама ағын
Егер бос орын болмаса немесе орын брондау кезінде бос болмай қалса, жүйе брондаудан бас тартып, бос орын жоқ деген хабарламаны көрсетеді.

## Қатысушылар
Жүргізуші, мобильді қосымша, Parking API, деректер базасы, шлагбаум.

## Нәтиже
Бронь деректер базасына сақталады, жүргізуші рұқсат алады немесе бос орын жоқ деген хабарламаны көреді.
